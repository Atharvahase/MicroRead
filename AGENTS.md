# Local-only workspace

- Keep all project files and generated artifacts on this computer.
- Do not deploy, publish, sync, upload source, or create cloud-hosted versions.
- Do not use shared-account Pages, Sites, Drive, GitHub, or other cloud storage for workspace content.
- Local preview servers must bind to `127.0.0.1`, not `0.0.0.0` or a LAN address.
- Ask for explicit user authorization before overriding any of these rules.
